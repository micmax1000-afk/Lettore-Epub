# EPUB Reader Web

Un lettore EPUB minimale ma funzionale, realizzato con [EPUB.js](https://epubjs.org/) e ospitabile su GitHub Pages.

## Funzionalità
- Caricamento di file EPUB tramite pulsante o drag & drop
- Navigazione pagina precedente/successiva (pulsanti e tasti freccia)
- Visualizzazione dell'indice (TOC) cliccabile
- Salvataggio automatico della posizione di lettura (localStorage)
- Barra di progresso

## Pubblicazione su GitHub Pages
1. Carica tutti i file in un repository GitHub.
2. Vai su Settings > Pages, seleziona branch `main` e salva.
3. L'app sarà live all'indirizzo: `https://<tuo-username>.github.io/<repo-name>`

## Libreria utilizzata
- EPUB.js (inclusa via CDN)
